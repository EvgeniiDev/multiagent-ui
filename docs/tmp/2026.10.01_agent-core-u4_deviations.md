## Принятые семантические решения U4

- Lease-expiry cancel БЕЗ пользовательского stop-интента → run `interrupted`
  (не `cancelled`): системная остановка ≠ user-stop; причина
  `lease expired during state-API outage` сохраняется в durable записи.
  Replay и online resolve используют ОДИНАКОВЫЙ маппинг.
- `child_pid:null` — не доказательство отсутствия ребёнка (control.py
  сериализует поле всегда). No-child только по явной launch-аттестации
  `childNone===true`/`childSpawned:false`; иначе retained.
- `removed` evidence при отсутствии ВСЕХ носителей recorded id-prefix;
  `stopped` — по документированным статусам exited/created/dead; статус
  вне LIVE_STATUSES∪STOPPED_STATUSES (напр. removing) → отказ.
- Custom hostname без preflight receipt → всегда отказ (hostname сама по
  себе не identity; отсутствие имени не доказывает удаление).
- `observedAt` для `stopped` = immutable `State.FinishedAt` → retry с тем
  же `--command-id` даёт байт-идентичный payload → domain replay-дедуп;
  либо already-retired short-circuit до любого docker/post вызова.
