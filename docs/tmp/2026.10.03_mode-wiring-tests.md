# Shared mode wiring regression tests

Scope: scripts/test_mode_wiring.mjs only; copied backend sources are the main
backend author's frozen fixture and are not part of this commit.

Seven tests run the production createStateService serialized request engine and
createInternalClient token-authenticated internal transport over isolated temporary
state, real Git fixture projects/worktrees, and real staged artifact import. No
listener, controller, model, agent process, deployment, or live state is used.

Verified seams:
- Inline UI AgentProfiles start Fusion implementation, Orchestrator and Swarm
  with the approved requirements/plan snapshots and inherited Core review roles.
- User and unauthenticated transports cannot issue internal Swarm authority.
- Swarm claim/begin/bind/cursor/observed/worker_settled/turn_result/materialized
  dispatch, descriptor hash/byte binding, phase ownership, stopped participant
  callback and live-attempt refusal before complete_run.
- Orchestrator committed decomposition descriptor, exact spec approval, ready
  task state, premature verifier refusal and failed worker callback.
- Fusion failed panel callback retains panel phase and consumes its retry budget.
- Explicit two-peer revision acknowledgments, Swarm declarations and completion
  reach awaiting_validation; a real owned Git worktree permits the standard Core
  validation reservation. Acceptance, terminalization and participant relaunch
  remain refused while that reservation is active.

Validation: node --test scripts/test_mode_wiring.mjs — 7/7 passed. Fixture setup
initially rejected empty plan checks, missing environment identity and malformed
IDs; corrected fixtures follow the actual production contracts. No source defect
was discovered in these bounded seams. This does not prove model behavior,
container isolation, physical worker barriers, execution of checks, successful
reviewer/checker evidence or production acceptance; separate real acceptance owns
those assertions.
