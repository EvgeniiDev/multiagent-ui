# Swarm canonical directory identity

Descriptor-relative writes kept edits inside an already opened parent, but an ancestor could be renamed away after pinning. The broker then reported an edit as applied to a detached inode while the live canonical path contained different bytes.

Journal version 3 records the exact root and touched parent device/inode identities. Fresh descriptor walks from the current canonical root reject symlinks and require both the held anchors and live path to match these saved identities. Checks run under the reader barrier, before and after tree operations, before the durable result, and before and after rollback writes. Recovery checks unfinished transactions even if a crash preceded the started or blocked marker.

An identity mismatch preserves the durable reader barrier and records a blocked transaction. Recovery, stop, and further edits remain blocked without writing into replacement paths. Returning the original directory identity permits exact beforeimage rollback, clears the block, and restores admission. Older journals without these bindings fail closed; no migration fabricates identities.

Adversarial directory/symlink replacement cases fail against the old broker because submit returns applied. The repaired cases cover swaps under freeze, immediately before mutation, after mutation, and before result publication, persistent restart barriers, and recovery after restoration. Additional root/parent replacement crash cases exercise recovery without a prior blocked marker.
