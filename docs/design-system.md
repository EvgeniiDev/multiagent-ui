# Дизайн-система Multiagent UI

Библиотека обязательна на всех экранах: новые и существующие кнопки и поля
используют общие примитивы. Их внешний вид не зависит от scoped-стилей
родительской страницы. Если нужного варианта нет, сначала расширьте библиотеку.

- `src/styles/tokens.css` — единый источник цветов, шрифтов, радиусов и состояний
  светлой/тёмной темы. Подключается в App.vue; существующая палитра сохранена.
- `src/components/ui/UiButton.vue` — все кнопки действий, вкладки, пункты меню,
  раскрытие и интерактивные строки. Нативный `<button>` допустим только внутри него.
- `src/components/ui/UiSelect.vue` — выбор со списком внутри панели, с темой,
  клавиатурой, фокусом и закрытием по Escape/нажатию снаружи. Нативный `select`
  с `ui-input` остаётся общим примитивом для обычных форм.
- `src/components/ui/UiExpandableRows.vue` — общий показ длинных списков:
  первые 20 строк и кнопка раскрытия остальных. Принимает `rows` и `controlsId`,
  передаёт видимые строки в слот `rows`; у таблицы/списка должен быть соответствующий
  `id`. Скрытие строк не меняет исходные данные, итоги или экспорт.
- `src/styles/controls.css` — классы `ui-input` для input/select/textarea,
  `ui-note` для пояснений, `ui-label` для подписей и `ui-surface` для отдельных
  смысловых блоков. Вариант `ui-surface-accent` выделяет результат для согласования. Подключается в App.vue.

## Кнопки

```vue
<script setup lang="ts">
import UiButton from '../../components/ui/UiButton.vue';
</script>

<template>
  <UiButton @click="close">Close</UiButton>
  <UiButton variant="primary" :disabled="busy" :aria-busy="busy" @click="save">Save</UiButton>
  <UiButton variant="danger" @click="remove">Delete</UiButton>
  <UiButton variant="ghost" size="xs" role="tab" :aria-selected="selected">Plan</UiButton>
  <UiButton icon aria-label="Reload state" @click="refresh">↻</UiButton>
</template>
```

| Свойство | Значения | Назначение |
|---|---|---|
| variant | secondary (по умолчанию), primary, danger, ghost, image, select, option, row, row-primary, tab, chip, transcript, session-tab | Обычное действие, основное, опасное, второстепенное/вкладка |
| size | sm (по умолчанию), xs | Высота 28 или 24 px; компактные кнопки для вкладок |
| layout | inline (по умолчанию), stacked | Иконка и подпись в строку или друг над другом для навигации |
| tone | default, danger, success, warning, muted, info | Семантический цвет для строк и других вариантов |
| reveal | boolean | Второстепенное действие внутри `ui-action-group`: видно при hover/focus на десктопе, всегда на touch |
| icon | boolean | Квадратная кнопка; обязательна доступная подпись aria-label |
| type | button (по умолчанию), submit, reset | Нативное поведение в форме |

`variant="image"` — кнопка-миниатюра без внутренних отступов, с курсором увеличения.
Для просмотра вложений используйте `src/components/ui/UiImagePreview.vue`: он
показывает миниатюру и открывает изображение в модальном диалоге.

Все нативные атрибуты и события передаются на настоящий button: disabled,
aria-busy, title, data-testid, click и т.д. Текст передаётся через default slot.
Компонент определяет hover, видимый клавиатурный фокус, disabled и выбранную
вкладку по aria-selected/aria-pressed; текущую страницу — по aria-current="page". Для узких экранов и touch-устройств
минимальная высота и ширина кнопки с иконкой — 44 px.
Исключение для плотной ленты: `variant="transcript"` — раскрытие tool calls,
24 px на десктопе и 32 px на touch, с моноширинным шрифтом и клавиатурным фокусом.
`tab` выделяет раздел нижней линией; `session-tab` используется внутри
`UiActionRow variant="tab"`, который объединяет название и закрытие общей рамкой.
Композер использует `ui-input--composer` внутри `ui-composer`: спокойный фокус
показывается рамкой контейнера, без прямоугольной обводки textarea.

## Правила использования

1. Используйте `UiButton` для всех кнопок, включая строки меню и раскрытие.
   Передавайте выбранное состояние через `aria-selected`, `aria-pressed`,
   `aria-checked` или `aria-current`, раскрытие — через `aria-expanded`.
   Не вкладывайте одну кнопку в другую: основное действие и trailing action
   размещайте рядом. Нативные ссылки с `href`, SVG-графики, drag handles и
   содержимое документов сохраняют свою семантику.
2. Поля: `ui-input` для input/select/textarea, `ui-checkbox` для checkbox/radio,
   `ui-range` для range, `ui-file` для file. Композер использует общий вариант
   `ui-input--composer`; моноширинное поле — `ui-input mono`.
3. Страница задаёт размещение, ширину и промежутки. Цвета, границы, шрифты,
   padding, hover, focus и disabled задаются только библиотекой через токены.
   Не копируйте CSS кнопок и полей в страницы и не добавляйте inline appearance.
4. Старые контролы подчиняются тем же правилам. Для специального варианта
   сначала расширьте общий компонент; локальные копии и исключения по страницам
   запрещены. Обработчики жестов, ARIA, disabled, v-model и тип значения
   сохраняются при миграции.
5. Перед выпуском проверяйте computed styles, hover, focus, disabled, настройки
   темы ОС, клавиатуру и узкий экран по TESTING.md. SSR и сборка не проверяют CSS.

## Автоматическая проверка

`npm run check:ui` разбирает Vue-шаблоны и стили всех файлов `src/**/*.vue`:
запрещает нативные кнопки вне `UiButton.vue`, поля без общих классов и локальные
переопределения внешнего вида контролов. Проверка запускается из `build` и
`build:web`, поэтому действует и в CI. Это статический барьер; он не заменяет
браузерную проверку, не анализирует HTML из документов и не доказывает поведение
жестов или соответствие доступности. Проверки самого барьера:
`node --test scripts/test_ui_library_policy.mjs`.

## Контекст и лимиты в сессии

`UiUsageMeter` показывает компактную кнопку с контекстом и немодальную панель
по нажатию или наведению мыши. Использует вариант `UiButton` `meter`, сохраняет
клавиатурный фокус и закрывается по Escape, уходу фокуса, нажатию снаружи или
деактивации сессии. `anchor` задаёт границу размещения: в чате это весь composer,
поэтому панель не перекрывает поле ввода. Содержимое создаётся только при открытии.

`SessionUsageMeter` объединяет контекст с компактным `SubscriptionLimits`.
Свойство `providerId` ограничивает показ текущим провайдером. Без данных
контекста для поддерживаемого агента остаётся индикатор `— tokens`; слово
`Limits` не заменяет счётчик. При получении данных показываются исходные
токены (`45k/200k`). Закрытые панели
не опрашивают API; в открытой доступны обновление, ожидание и обработка ошибок.

## Таблицы статистики

`src/components/ui/UiUsageTable.vue` показывает имя, метаданные, токены,
сообщённую стоимость и долю. На телефоне это компактная строка: имя и
метаданные сверху, три показателя ниже. Полное имя остаётся в DOM и `title`;
стоимости разных валют не объединяются в одну сумму.

Для длинных таблиц используйте `UiExpandableRows` со слотом `rows` и
`showCount`: счётчик и кнопка раскрытия находятся над таблицей. `controlsId`
должен совпадать с `id` таблицы. Для хронологических данных можно задать
`collapsedLabel="Show latest 20"`. Сортировка, поиск и расчёты выполняются
до ограничения видимых строк; экспорт получает полный набор данных.

## Список сессий на телефоне

На узком экране есть общая страница сессий и экран открытого чата. Список
использует `SessionList presentation="page"`: строки не имеют выбранного
состояния, `aria-pressed`, обводки текущей сессии, точек открытых вкладок или
метки Open или общей панели подключения текущей вкладки. Статусы подключения,
работы, ошибок, разрешений и непрочитанных ответов показываются у нужной строки.
Действие рядом с сохранённой сессией — архивирование; незавершённое создание
можно отменить. В desktop sidebar сохраняется представление вкладок.

## Строка с основным и дополнительным действием

`UiActionRow` объединяет основной `UiButton variant="row-primary"` и кнопки
в слоте `actions` в одну плашку. Фон, рамка и скругление принадлежат строке;
действия остаются отдельными соседними кнопками. `selected` выделяет всю плашку,
включая действие справа. `as="li"` сохраняет семантику списка,
`density="comfortable"` задаёт высоту строки для мобильной страницы сессий.

`variant="tab"` задаёт компактную вкладку с верхними скруглениями; рамка и фон
выбранной вкладки охватывают также действие закрытия. Клавиатурный фокус
кнопок остаётся внутри общей плашки.
