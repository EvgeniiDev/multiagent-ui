# Бэклог панели

**Живой список задач — только доска.** Этот файл больше не перечисляет задачи: он
разошёлся с доской в течение дня, и два источника правды гарантированно расходятся.

    boardctl list                 # всё, что есть
    boardctl list --stage dev     # что в работе
    boardctl show <id>            # карточка целиком: описание, приёмка, проверка

Панель показывает то же самое на вкладке Board (ноутбук и телефон видят одну доску).

## Где мы сейчас

Точка входа: **B4 (канбан-конвейер)** — то, что владелец просил увидеть (колонки-стадии + статус у
карточки), и **B3** — почему кнопка создания проекта была недостижима. Следом — **C1** (состояние на
хост), без него «работать через панель» упирается в открытую вкладку, затем **C2/C3** (роли и
диспетчер) и **C7** (PM).
