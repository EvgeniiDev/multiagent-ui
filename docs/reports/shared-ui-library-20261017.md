## Что было пропущено при первой проверке

Первый браузерный прогон проверял основные действия и общие размеры контролов,
но не плотную смешанную ленту tool calls и фокус textarea композера. Пользователь
показал обе регрессии. На исходной сборке воспроизведены белый outline 2 px,
высота раскрываемых строк 44 px рядом с обычными 24 px и смена их шрифта.
Новая проверка падала до исправления. Расширенный прогон также воспроизвёл
горизонтальное переполнение ACP Traffic на 320 px.

## Исправления

- Композер: общий `ui-input--composer` без прямоугольного outline;
  `ui-composer` показывает спокойный фокус рамкой. Размер шрифта на телефоне
  остаётся 16 px, чтобы не провоцировать масштабирование поля.
- Tool calls: общий `UiButton variant="transcript"`, 24 px desktop / 32 px touch,
  моноширинный шрифт, сохранённые раскрытие, Enter, фокус и статусные оттенки.
  Исключение плотной ленты из общего размера 44 px описано в дизайн-системе.
- Второстепенные действия вкладок, списка сессий и карточек: общий `reveal`
  внутри `ui-action-group`; видимы при hover/focus на desktop и всегда на touch.
- Вкладки разделов снова используют нижнюю линию; отдельный общий `session-tab`
  сохраняет фон и рамку активной вкладки сессии.
- История запусков и её действия используют компактный `size="xs"` на desktop,
  сохраняя обычный touch-размер. Статусы done/accepted имеют общий muted tone.
- Поле роли колонки сохраняет моноширинный шрифт; `aria-invalid` окрашивает
  границу и текст через общий примитив. Мобильный шрифт остаётся 16 px.
- Шапка ACP Traffic переносит контролы на узком экране; поиск, очистка,
  pause/resume и фильтр остаются доступны.

Оформление кнопок и полей принадлежит библиотеке; локальный CSS задаёт компоновку.
Чужие незакоммиченные изменения сохранены, сборка подготовлена из отдельного checkout.
